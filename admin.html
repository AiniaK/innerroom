打開房間

物件說明與彈窗

每一列三個欄位：有滑鼠圖示的是游標移上去時顯示的名稱，第二個是彈窗標題，第三個是彈窗裡的說明文字。取消勾選「點擊時顯示彈窗」，點這個物件就不會跳出視窗（坐下、開關燈這類動作不受影響）。

展品

每個展品右邊都有白牆的即時示意（面向白牆看）：紅框是這件展品，棕框是其他展品，修改數字時會立刻更新。水平位置以公尺計，數字越大越靠左；高度是畫框中心離地的高度；寬度是畫框的寬（公分）。勾選「收進收納箱」就不會出現在牆上，取消勾選就放回牆上。

media/ 資料夾裡的檔案

這裡列出網站上所有的影片、音樂和封面。正在使用的檔案不能刪除；先在上面換掉或移除，按「儲存並更新房間」後才能刪。

檔案大小狀態
檔案太大、上傳不了時：改用 GitHub 網頁上傳
  1. 打開 GitHub 上的 media 資料夾上傳頁面（需要用你的 GitHub 帳號登入）。
  2. 把檔案拖進頁面。檔名建議只用英文、數字和「-」，例如 tv-sea-2026.mp4。
  3. 拉到頁面最下面，按綠色的「Commit changes」。
  4. 等大約 1 分鐘，回到這裡按「重新整理檔案清單」。
  5. 新檔案會出現在電視的「播放哪一支影片」選單，或平板音樂的下拉選單裡。選好之後按「儲存並更新房間」。

GitHub 網頁一次最多只能上傳 25 MB 的檔案。更大的檔案（最多 100 MB）要用 GitHub Desktop 放進 media 資料夾再 Push。不過影片太大，訪客用手機打開房間時會載入很久，建議盡量壓縮在 20 MB 以內。

留言管理

這裡的操作會立即生效，不需要按「儲存並更新房間」。你也可以直接在 Notion 的留言資料庫裡勾選或取消勾選「公開」，效果相同（房間最多約 3 分鐘後更新）。

已封鎖的 Google 帳號

被封鎖的帳號不能再用 Google 登入留言。對方仍然可以不登入、匿名留言，但匿名留言都要經過你審核才會公開。這裡只顯示雜湊後的代號，不會顯示對方的 Google 名字或 email。
